# 课程详情页底部悬浮工作台设计

## 目标

让用户在长篇课程阅读过程中，始终可以切换中文、英文和 Cue，控制英文播放模式，并查看当前播放进度，不需要滚回页面顶部。

保留现有能力：中文、英文、Cue 三种内容模式；英文分段字幕；播放时自动高亮和滚动；点击任意段落跳转播放；切换内容模式不卸载音频；单篇和循环播放。

## 设计方向

采用底部悬浮工作台，而不是把控制区继续放在标题下方。正文保持开放、轻量的阅读版式，工作台作为独立的持续操作层。

### 桌面端

- 工作台固定在视口底部，距离底边 18px，最大宽度与阅读页一致。
- 使用半透明暖白表面、细边框和轻微阴影，与页面底色融合，不做厚重卡片。
- 第一行显示模式切换和播放模式；第二行仅在英文模式显示音频原生控制条和当前播放段信息。
- 工作台不覆盖正文，`reader-page` 在底部预留足够 padding。
- 工作台宽度不超过阅读列，避免控制元素横跨过宽导致注意力分散。

### 手机端

- 工作台固定在底部，使用 `env(safe-area-inset-bottom)` 处理 iPhone 底部安全区。
- 第一行是三段式模式切换，按钮保持易点击尺寸；播放模式使用单个图形按钮。
- 第二行是完整宽度播放条，播放段信息以低权重辅助文字显示，过长时截断。
- 工作台不使用蓝色点击覆盖，不产生横向滚动；页面底部保留工作台高度加安全区间距。
- 内容切换和播放控制都保持在拇指可触范围内。

## 组件与状态

`CourseReader` 继续持有阅读状态，但将控制区拆成独立的 `ReaderWorkbench` 组件，减少页面主体和控制逻辑的耦合。

工作台接收：

- 当前 `mode` 和模式切换回调；
- `playMode` 和切换回调；
- 当前 `HTMLAudioElement` 控制引用；
- 当前播放段、总段数和当前段文本；
- 音频是否存在以及是否处于英文模式。

音频元素保持单一实例并稳定挂载。模式切换只改变正文视图和工作台可见状态，不改变 `src`、`currentTime` 或播放状态。

## 交互规则

1. 用户滚动正文时，工作台始终固定在底部。
2. 点击中文、英文或 Cue，正文立即切换；正在播放时不暂停、不重置进度。
3. 非英文模式下，音频仍保持挂载，工作台保留必要的播放控制，但弱化当前段信息；切回英文后恢复完整字幕状态。
4. 点击播放条原生播放按钮可以开始或暂停；点击英文段落仍然跳转到该段开头并播放。
5. 播放模式图标只表达“当前模式”，无额外文字标签；无障碍标签说明当前模式和下一步动作。
6. 播放进度变化时只更新当前段和工作台辅助文字，避免让整篇正文无意义地重渲染。
7. 当前段自动滚动时使用 `scrollIntoView`，但不能滚动整个页面把工作台下方内容遮住；段落滚动目标需要保留工作台安全间距。
8. 没有音频时工作台仍提供模式切换，但不渲染空的播放区域。

## 视觉规则

- 继续使用项目现有暖白、深蓝灰、绿色强调色，不引入新的品牌颜色。
- 工作台边界依靠间距、细边框和柔和阴影表达，不使用高饱和背景。
- 激活模式使用白色表面和轻微抬升；未激活模式使用低对比度文字。
- 播放中的段落和工作台当前段使用同一绿色强调色，建立关联但不喧宾夺主。
- 所有按钮提供键盘焦点样式；触屏设备移除浏览器默认蓝色高亮。
- 工作台的 z-index 高于正文但低于系统级弹层，避免遮挡导航和错误提示。

## 验收标准

- 桌面端滚动到文章中段时，模式切换和播放控制仍可见、可用。
- 手机端 390px 左右宽度下，工作台不横向溢出，按钮可点击，安全区间距正常。
- 中文、英文、Cue 之间切换不会切断正在播放的音频。
- 英文播放时当前段高亮、自动滚动和点击跳转继续有效。
- 单篇 / 循环图形按钮继续可用，并能被屏幕阅读器识别。
- 工作台不会遮住当前段落、完成按钮或正文最后一行。
- 页面无新的控制台错误，课程详情页、音频请求和已有模式切换测试通过。
