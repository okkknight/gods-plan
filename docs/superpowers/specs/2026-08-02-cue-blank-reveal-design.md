# Cue 填空点击揭示设计

## 目标

在 Cue Version 页面中，让用户点击任意一个下划线填空区，查看该位置对应的英文原文；再次点击同一填空区恢复隐藏状态。

## 交互

- 每个填空区独立控制显示状态，点击一个不会影响其他填空。
- 隐藏状态继续使用现有的下划线加空格排版。
- 展开状态显示英文原文对应的词或短语，并保留在原句中的位置。
- 展开后的原文仍是可点击按钮，再次点击恢复下划线。
- 不增加说明性文案、全局展开按钮或额外面板。
- 切换课程或重新进入 Cue 页面时，填空恢复为隐藏状态。
- 使用键盘也可操作，按钮提供清晰的可访问名称。

## 数据与渲染

- 英文原文是隐藏内容的唯一来源，Cue 文本只负责提供可见骨架和填空边界。
- 通过 Cue 中的下划线占位符与英文中的可见文本顺序匹配，为每个占位符提取对应原文。
- 如果某个占位符无法可靠匹配，不显示猜测内容，继续显示原下划线，避免破坏学习材料。
- Markdown 标题、列表、强调、代码和链接的现有渲染行为保持不变。

## 样式

- 填空按钮无默认蓝色背景，保持当前文字颜色和下划线视觉。
- 悬停、聚焦和展开状态使用轻微颜色变化与圆角内边距，避免移动端出现整块蓝色覆盖。
- 触控目标不小于可操作尺寸，但不改变文章行高和段落结构。

## 验收标准

1. Cue 页面仍能显示下划线填空。
2. 点击第一个填空后，只显示第一个对应英文片段。
3. 再次点击后，第一个填空恢复下划线。
4. 点击第二个填空时，第一个状态不被意外切换。
5. 原有英文音频、模式切换、Markdown 展示和移动端布局测试继续通过。
