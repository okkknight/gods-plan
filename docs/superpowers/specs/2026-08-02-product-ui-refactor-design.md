# God's Plan 整体产品 UI 与交互重构设计

## 目标

将当前可用但偏原型化的 God's Plan，重构为一个安静、有质感、低压力、适合长期学习的英语学习工作台。

## 产品方向

视觉与交互采用“安静、有质感的英语学习工作台”方向：

- 以编辑感排版和清晰层级建立产品质感。
- 使用温和纸张背景、深墨色文字和低饱和绿色作为主色。
- 通过间距、字体、边界和微妙反馈建立层次，而不是堆叠颜色和装饰。
- 每个页面只突出当前最重要的学习动作。
- 桌面端舒展阅读，移动端优先保证单手操作与触控稳定性。

## 不变约束

- 不改变课程内容、Cue 原文、音频文件、音频分段和复习调度逻辑。
- 不向用户展示“逾期”概念；逾期只保留为内部调度逻辑。
- 每日复习展示上限继续为 3 条。
- 英文、中文、Cue 模式切换时不打断音频状态。
- Cue 填空继续支持点击展开和再次隐藏。
- VPS 只同步生产运行时依赖的数据和构建产物。

## 信息架构

### 全局导航

- 桌面端保留品牌、今日、日历、课程库三个主入口。
- 当前入口必须有清晰但克制的选中状态。
- 移动端采用更适合拇指操作的底部导航或紧凑顶部导航，最终以第一阶段视觉验证结果确定。
- 页面标题、日期、状态和主要动作统一使用相同的层级规则。

### 今日页

今日页是产品首页，信息顺序固定为：

1. 日期与页面标题
2. 今日完成进度
3. 首要学习任务
4. 今日复习
5. 今日新学
6. 今日已完成
7. 日期前后切换

规则：

- 空的任务分组不渲染。
- 整张课程卡片负责进入课程，避免卡片和内部按钮产生重复操作层级。
- 不显示逾期、压力提示或解释性营销文案。
- 复习任务和新课任务使用一致的卡片结构，只通过状态标签和次级信息区分。
- 完成状态使用轻量反馈，不使用打断式弹窗。

### 课程详情页

课程详情页围绕“阅读 / 听读 / 回忆”组织：

- 顶部显示返回、集数、课程标题和当前学习阶段。
- 正文区域优先展示当前模式内容，减少标题区占用。
- 底部悬浮工作台固定提供模式切换、播放控制、播放模式和当前段信息。
- 文章较长时，工作台必须始终可用且不遮挡当前内容。
- 英文段落点击播放、字幕同步、Cue 填空展开都保留并统一焦点与高亮规则。
- 完成操作位于正文之后，保持学习动作的自然终点。

### 课程库

- 从单纯长列表升级为可浏览的课程目录。
- 保留季 / 集编号、课程标题和学习状态。
- 统一状态：未开始、学习中、复习中、已完成、已归档。
- 增加搜索和状态筛选，但不引入复杂统计面板。
- 预览进入课程详情；归档使用明确的低风险操作和二次确认。
- 手机端改为易点击的课程卡片。

### 日历

- 日期前后切换与今日页保持一致。
- 当前日期、过去记录、未来计划使用不同但克制的视觉层级。
- 未来计划显示任务本身，减少解释性段落。
- 统一空状态、无记录状态和无计划状态。
- 日历服务和调度逻辑保持不变，只重构呈现与交互。

## 视觉系统

建立独立的设计 Token 层，至少包括：

- `color`: ink、muted、paper、surface、line、accent、danger、focus。
- `type`: display、heading、body、label、caption、英文阅读字体。
- `space`: 页面边距、区块间距、卡片内边距、控件间距。
- `radius`: small、medium、large、pill。
- `shadow`: subtle、floating、focus。
- `motion`: hover、press、selected、reduced-motion。

基础组件统一提供：

- Button
- Badge / Status
- Card
- SectionHeader
- EmptyState
- Dialog / Confirm
- Toast / InlineFeedback
- DateNavigator
- BottomWorkbench

组件要有明确的默认、hover、pressed、focus-visible、disabled、loading 状态，并优先保证移动端触控体验。

## 代码重构边界

- 将 `globals.css` 中的设计变量、基础组件、页面布局和页面专属样式分层整理。
- 将今日页、日历页中的重复任务分组和状态呈现抽成可复用组件。
- 保持服务层、数据库层、调度层接口不变。
- 课程详情页只拆分有清晰职责的阅读头部、正文、模式切换和底部工作台，不做无收益的大规模文件拆分。
- 新增 UI 组件必须有可独立验证的行为或视觉验收点。

## 分阶段交付

### Milestone 1：视觉基础与今日页

- 完成设计 Token、基础控件和全局布局。
- 重构导航、页面标题、课程卡片、任务分组、进度区和日期导航。
- 完成桌面端与 390px 手机端验收。

### Milestone 2：课程详情页

- 重构阅读头部、正文排版、英文段落、Cue 交互和底部工作台。
- 保证音频元素稳定、播放模式稳定、段落点击跳转稳定。
- 完成桌面端长文阅读与移动端底部工作台验收。

### Milestone 3：课程库、日历与收尾

- 重构课程目录、筛选、归档确认和课程状态。
- 重构日历日期浏览、历史记录、未来计划和空状态。
- 完成统一动效、可访问性、响应式和回归测试。

## 验收标准

- 今日页首屏能明确表达“今天先做什么”。
- 课程卡片在桌面和手机端点击反馈一致，不出现系统蓝色覆盖。
- 课程详情页正文阅读时，模式和播放控制始终可用且不遮挡内容。
- 中文、英文、Cue 切换不打断音频；Cue 填空展开与隐藏稳定。
- 课程库和日历拥有统一的状态、空状态和操作反馈。
- 390px、430px、768px、桌面宽度均无横向溢出和不可用控件。
- 键盘焦点、按钮名称、音频控制和填空交互满足基本可访问性要求。
- 现有单元测试、端到端测试和生产构建继续通过。
- 发布前只同步 VPS 运行时需要的构建产物、静态资源和必要数据。

## 明确不做

- 不增加社交、排行榜、积分、勋章或复杂数据分析。
- 不重写复习算法和课程生产流程。
- 不更换音频模型或重新生成音频。
- 不在第一阶段引入新的前端框架或组件库。
