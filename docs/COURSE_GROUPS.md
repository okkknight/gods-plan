# 课程组

当前两组为「摩登家庭 · 第一季」（24 课）与「乔布斯 · 斯坦福毕业演讲」（5 课）。在课程库顶部选择当前学习组，选择保存在 SQLite 中；刷新或重新启动应用后仍保留。

## 学习行为

- 今日新课、复习、积压判断、已完成记录、历史日历和未来预测都只使用当前组的数据。每天的新课额度、复习展示上限按组计算。
- 各组依照自己的课程顺序推进；一组学完不会自动开始另一组。
- 切换不会重置进度、删除记录或平移复习日期。切回旧组后，已经到期的复习仍按原日期作为待复习处理。
- 今日与日历显示当前组名称，点击可返回课程库切换。
- 从旧标签页提交其他组的完成、撤销、归档或更新会被拒绝。直接访问未选中组的课程页面会返回课程库。
- 在课程库导入 JSON 时，新课归入当前组；更新已有课程不会移动其所属组。命令行导入未指定组时，根据已知课程前缀或 series 推断，未知且无系列的课程归到「其他课程」。

## 数据与迁移

新增 `course_groups` 与 `app_settings` 表，`courses.group_id` 引用课程组。首次默认选中摩登家庭。

`src/db/course-group-migration.ts` 提供幂等迁移，由应用数据库连接初始化及 `db:migrate` 调用。已有 29 课按 slug 分组；原有课程字段、段落、状态、学习进度和事件不变。重复运行不会覆盖当前课程组选择。

本地迁移前备份：`data/english-learning.db.pre-course-groups-2026-10-16T09-52-25-365Z`。已逐字段比较原有课程内容，并比较所有学习进度/事件的摘要，确认一致。

部署时须先备份线上 SQLite，再发布构建。首次加载新构建会执行上述增量迁移；不能用本地数据库覆盖线上数据库，也无需重新发布音频或安装依赖。数据库中保留新增表与列不妨碍旧构建读取已有字段，因此前端可单独回退。
